# iPartment: Next Generation (申大附中风云录)

这是一部以《爱情公寓》第二代为主角的校园群像小说。

主要讲的是曾小贤和胡一菲的儿子**曾小乙**，在高一后排课桌上开办“课文抽背险”，三年时间里一步步在申大附中折腾出集**校内保险、违禁品物流、班级公债、破产清算**于一身的校园影子金融体系的故事。

- **全书篇幅**：全三季完结，共 31 话正文 + 1 篇条约附录
- **全书字数**：约 20 万字（纯汉字 17.3 万）
- **阅读方式**：纯 Markdown 编写，在 GitHub 网页端或 VS Code 预览均可获得极佳的摸鱼体验。

## 🏫 申大附中·人气教工图鉴

* **王老师（高一/高二班主任·机房常客）**  
  全校第一通透的摸鱼大师。表面信奉“多一事不如少一事”的消极待工哲学，遇事就往机房躲；实则是洞悉体制规则与人性的老油条。在第三季面对校方无理摊派时，敢以“蓄意逼反家长”的反向操作四两拨千斤，深得学生爱戴。
* **陈老师（硬核骨干老教师）**  
  附中传统老派师德的良心担当。性情刚直火爆，敢在校领导会上公开拍桌子揭盖子。虽然平时对学生要求极严，但在体制风波与利益冲突中，始终是挡在学生和年轻教师身前最硬的一堵墙。
* **吴老师（年级组长）**  
  经典教条主义管理者，极度热衷于搞折腾学生的“吃苦教育”。行事官僚且欺软怕硬，全书常年作为主角团商业博弈、测试漏洞与反向套利的“靶子”。
* **空降领导组（袁校长 & 赵主任）**  
  好大喜功的行政派代表。执着于搞宏大叙事与表面政绩，一手主导了高开支、层层摊派的课本剧大工程，直接点燃了第三季校内劣质公债与集体赤字危机的大导火索。
